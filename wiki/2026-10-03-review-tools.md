## 구현 범위

- 내보내기를 준비하는 동안 요청이 응답 없이 기다리던 동기 화면 흐름을 작업 생성·상태 조회·취소·다운로드로 바꿨다. 기존 동기 ZIP/Excel API는 유지한다.
- 문서 목록의 체크박스 선택을 Excel/ZIP 내보내기로 연결했다. 선택은 페이지와 필터를 넘어 유지되고, 결과 전체 선택 버튼으로 현재 검색 결과만 선택할 수도 있다. 선택한 비활성 문서도 명시적인 선택 내보내기에 포함한다. 서버는 ID를 검증하고 중복을 제거하며 문서 자연 순서를 유지한다.
- 작업 패널은 처리 문서 수·경과 시간·파일 마무리 상태·오류·취소·다운로드 재시도를 표시한다. 준비 완료와 브라우저 다운로드 시작을 구분하고, 한 화면 세션에서 중복 실행을 막는다. 화면을 이동해도 패널이 유지된다. 상태 확인 연결 오류는 새 작업을 만드는 대신 기존 작업을 다시 확인할 수 있다.
- 작업 메타데이터·취소 신호와 결과 파일은 `.cache/export-jobs`에 저장하며 모든 uvicorn 워커가 공유한다. 파일 잠금으로 상태 변경을 보호하고 데이터 디렉터리 전체 실행 2개·대기와 실행 합계 20개로 제한한다. 완료물은 24시간 뒤 후속 작업 요청 때 정리한다. 워커 종료로 남은 작업은 실패로 전환한다.
- ZIP 복사 중 1 MiB 단위와 문서 경계에서 취소를 확인한다. XLSX는 문서 경계 및 파일 저장 전후에 확인한다. 마무리 저장 도중 취소된 결과도 공개하지 않는다. XLSX 마무리 저장 자체는 즉시 중단되지 않을 수 있다.
- Golden의 첫 변경 이전 상태와 생성·저장·삭제·복원 결과를 번들 `.history/golden`에 보관한다. 기존 버전 목록을 페이지로 조회하고 내용을 미리 본 뒤 복원한다. 삭제한 Golden도 기록에서 복원할 수 있다. 복원 자체도 기록으로 남긴다.
- 저장·삭제·복원은 문서별 파일 잠금 안에서 읽어 온 버전을 비교한다. 상세의 Golden과 SHA-256 revision은 같은 바이트 스냅샷에서 나오며 쓰기 응답도 쓰기 잠금 안에서 구성하여 경쟁 저장의 응답을 뒤섞지 않는다. 다른 탭의 변경이 있으면 409이고 덮어쓰지 않는다.
- 화면은 충돌 시 자동 저장을 멈추고 로컬 편집 내용을 보존한다. JSON 보관과 최신 내용 불러오기를 제공한다. 복원 전에는 미저장 변경을 저장하거나 버리는 선택을 요구한다. 미저장 상태로 화면을 떠나거나 새로고침하면 이동 확인을 받는다.

## 문제 유형과 안전 처리

작업 상태 공유 부재와 조건 없는 쓰기로 생기는 문제를 데이터 디렉터리 공유 상태, 문서별 원자적 버전 확인, 직렬 저장 큐로 처리했다. Golden 내용·revision 불일치, 저장 뒤 삭제 경합, 삭제한 문서의 이력 접근, 원래 업로드된 UTF-8 BOM·CP949 버전의 미리 보기·복원도 함께 검증했다. 기록 저장 실패는 이전 Golden을 보존하도록 되돌린다.

## 검증

- 백엔드 전체 회귀 101개 통과. 선택 Excel/ZIP 내용, 작업 상태·다른 프로세스 상태 조회와 취소, 대기·실행·완료 취소, 준비 상태, 워커 종료와 대기 한도 복구, Golden 생성·저장·삭제·복원, stale 쓰기·동시 쓰기·응답 revision 일관성, BOM·CP949 복원과 기록 실패 rollback을 검사했다.
- 실제 임시 데이터 서버(2워커)에서 선택 문서 XLSX가 다른 문서 없이 다운로드되는 것을 확인했다. 두 탭의 저장 충돌, 로컬 JSON 다운로드, 최신 상태 다시 읽기, 이력 미리 보기·복원도 확인했다. 사용자 저장 데이터에는 쓰지 않고 더미 번들로 검증했다.
- 브라우저 회귀 검사 통과: 편집 중 저장·실패 후 큐 복구, revision 갱신, 충돌 중 로컬 값 보존과 JSON 보관·최신 상태 불러오기, 이력 페이지·복원 및 Golden 삭제 후 생성 안내 화면에서 복원, 내보내기 준비·중복 방지·요청 전/실행 중 취소·재시도·연결 복구, 서로 다른 페이지의 선택 2건 전송.
- 브라우저 재현 스크립트: `scripts/verify_editor_save.py`, `scripts/verify_golden_history.py`, `scripts/verify_export_ui.py`. 선택 사항인 Playwright·Chromium이 필요하다.

## 사용과 제한

내보내기는 목록·상세의 내보내기 메뉴, Golden 기록은 편집 패널의 `버전 기록`에서 연다. 작업 패널은 현재 페이지 세션에서 유지되며 브라우저를 새로고침한 뒤 자동으로 다시 연결하지 않는다. 이력은 이 기능 적용 후의 변경부터 생기며 과거 편집을 소급 복원하지 않는다. 번들을 삭제하면 이력도 삭제된다. 기존 클라이언트 호환 때문에 revision을 생략한 API 쓰기는 허용하며 새 편집 화면은 항상 revision을 전달한다. 인증 사용자가 없는 앱이므로 변경자 이름은 기록하지 않는다.
