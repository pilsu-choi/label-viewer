## 배경

요청 사항:

1. 번들 안 문서(이미지·JSON 묶음)를 활성·비활성으로 나누고, 여러 건을 한 번에 바꿀 수 있어야 한다.
2. 다운로드는 활성 목록과 비활성 목록을 각각 받을 수 있어야 한다.
3. 정확도 집계도 활성·비활성 범위별로 볼 수 있어야 한다.
4. 골든셋이 3,500건 이상이 될 예정이라 페이지네이션이 필요하다.

비활성화 단위는 문서이고, 새 문서의 기본값은 활성이다.

## 변경

| 위치 | 내용 |
|---|---|
| `backend/bundle.py` | `_state.json` 에 `disabled` 목록을 저장한다(기본 활성이라 비활성 문서만 저장). `set_enabled` 는 여러 문서를 한 번에 바꾼다. `update_state` 는 `.state.lock` 에 `fcntl.flock` 을 걸고 읽기-수정-쓰기를 한다(`set_review` 도 같은 경로). 집계는 `_aggregate` 로 분리했고, `bundle_view` 가 `summary`(전체)와 `summary_by_scope.enabled/disabled` 를 함께 준다. 문서 요약에 `enabled` 를 넣었다 |
| `backend/bundle.py` 캐시 | 문서 요약을 별도 저장소 `_SUM_MEMO`(상한 50,000)에 둔다. 기존에는 파싱 JSON 캐시와 같은 4,096 상한을 써서 3,500건이면 조회 중에 캐시가 계속 비워졌다 |
| `backend/export.py` | ZIP·Excel에 `scope=enabled|disabled` 를 추가했다(기본 enabled). `doc` 단위 내보내기는 활성 여부와 무관하다. ZIP은 `storage/.cache/tmp/` 임시 파일에 쓰고, PNG·JPEG·WebP는 다시 압축하지 않는다 |
| `backend/app.py` | `PUT /enabled`(응답 = 번들 화면 데이터). ZIP은 `StreamingResponse` 로 1MB씩 보낸다. 파일명은 `-disabled` 접미사를 붙이고 UTF-8 인코딩이다 |
| `frontend/js/list.js` | 집계 범위 세그먼트(전체/활성/비활성, 개요·칩·목록 모두 적용), 카드·행 체크박스(Shift 범위 선택), 선택 바(이 페이지·결과 전체 선택, 활성화·비활성화), 페이지네이션(50/100/200, `lv.pageSize` 저장), 내보내기 메뉴를 활성·비활성 그룹으로 나눔(0건이면 비활성 표시) |
| `frontend/js/documentRail.js` | 100건씩 끊고 현재 문서가 있는 묶음을 기본으로 보여 준다. 비활성 문서는 흐리게 "비활성"으로 표시한다 |
| `frontend/js/api.js` | `setEnabled` 는 응답으로 받은 번들을 문서 이동 캐시에도 넣는다. 내보내기 URL에 `scope` 를 추가했다 |

## 결정

- **페이지네이션은 클라이언트에서**: 번들 응답은 3,500건이어도 gzip 후 약 48KB다. 서버 페이지네이션을 하면 필터·검색·유형 수·범위 집계를 모두 서버로 옮겨야 한다. 무거운 것은 DOM이라 화면에서만 끊는다.
- **집계 범위와 목록 범위를 하나로**: 같은 세그먼트가 개요 수치와 목록을 함께 바꿔서, 보이는 숫자와 보이는 문서가 어긋나지 않는다.
- **선택은 필터·페이지를 넘어 유지**: 여러 페이지에서 골라 한 번에 바꿀 수 있다. 바꾼 뒤에는 선택을 비운다.
- **Excel `요약` 합계는 내보낸 범위 기준**: 활성 Excel의 합계가 화면의 "활성" 범위 정확도와 같다.

## 검증

- `pytest` 46개 중 45개 통과(`test_enable_disable_docs` 추가). 실패 1건 `test_upload_hardening`(한글 90자 파일명)은 작업 전 dev에서도 macOS에서 실패한다(파일시스템 파일명 길이 제한 차이).
- 3,500건 더미 번들(dummy 6종 복제), 로컬 측정:
  - 번들 조회: 첫 조회 1.4s / 캐시 후 0.18s(dev 0.66~0.71s). 응답 gzip 48KB.
  - 활성 3,495건 Excel 12.6s(690KB), 전체 묶음 ZIP 15.9s(91MB). 임시 파일은 남지 않는다.
- Playwright: 첫 페이지 카드 50개, Shift 범위 선택 5건 비활성화 후 범위 수 `3500/3495/5`, 2페이지 `51–100`, 비활성 범위 카드 5개·개요 `0 / 5`, 비활성 ZIP `big3500-disabled.zip` 에 5문서만 포함, 200개씩 보기, 상세 레일 `1201–1300 / 3500` 에 현재 문서 표시, 비활성 문서 레일 표시, 콘솔 오류 없음.

## 남은 것

- 상세 화면에서 현재 문서 하나를 바로 활성·비활성하는 버튼은 없다(목록 화면에서 바꾼다).
- 대용량 Excel·ZIP은 서버가 다 만든 뒤 내려보내기 시작해서 그동안(3,500건 기준 10초대) 브라우저에 진행 표시가 없다.
