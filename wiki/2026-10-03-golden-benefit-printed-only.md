## 원격(AWS) 뷰어 반영 절차 (실행하지 않음)

원격 뷰어는 로컬 `label_veiwer/storage`를 읽지 않고 서버 `/mnt/data/label-viewer`의 docker 볼륨 `data:/data`에 번들을 따로 둔다. 로컬 편집이 자동 반영되지 않는다. 업로드는 `POST /api/bundles`로 하며(`backend/app.py`), 문서 종류별 `original`·`preprocessed`·`ao_extract`·`golden`·`harness` 폴더 구조의 ZIP 또는 폴더를 받는다. 번들 ID는 시각+해시라 같은 번들을 덮어쓰지 못하므로 **삭제 후 재업로드**한다.

1. 터널: `cd label_veiwer/deploy/aws && ./tunnel.sh`(`localhost:18765` → 서버 `127.0.0.1:8765`). 보안그룹 8765가 열려 있으면 서버 주소로 직접 호출. 아래 `V`는 그 주소.
2. 원격 현황·검수 상태 확보: `curl $V/api/bundles`로 번들 ID와 이름을 확인한다. 원격에서 사람이 이미 고친 정답이 있을 수 있어(검수·`PUT golden`) 덮어쓰기 전에 `curl -o remote-<id>.zip "$V/api/bundles/<id>/export/bundle.zip"`으로 내려받아 로컬 정답과 비교하고, 원격에만 있는 수정은 합친다.
3. 로컬 번들 압축(수정 반영본): `cd label_veiwer/storage/bundles/20260930-1444-5491 && zip -r /tmp/0930_golden_aws_harness.zip original preprocessed ao_extract golden harness`. 205건은 `20260929-1627-2965`를 같은 방식으로 묶는다(205건은 `e2e/make_label_viewer_bundle.py`로 만든 구조와 같다). 번들의 `_state.json`(검수 상태·이름)은 업로드로 전달되지 않으므로 재업로드 뒤 검수 완료 표시가 필요하면 `PUT /api/bundles/<id>/docs/<doc>/review`(`{"review":"done"}`)로 다시 넣는다.
4. 삭제(사용자 확인 뒤): `curl -X DELETE $V/api/bundles/<old_id>`(204). 번들 안 편집·검수 내용이 사라지므로 2단계 백업이 있어야 한다.
5. 업로드: `curl -F name=0930_golden_aws_harness -F files=@/tmp/0930_golden_aws_harness.zip $V/api/bundles`. 응답의 새 번들 ID를 기록한다. 폴더째는 `-F "files=@경로"`를 파일마다 반복한다.
6. 확인: `curl $V/api/bundles/<new_id>`로 문서 수(59·205)를 보고, 급여 칸이 빈칸인지 대표 문서 `curl $V/api/bundles/<new_id>/docs/20230104_123952`로 확인한다. 이 작업은 뷰어에서 사람이 쓰는 정답 원본을 교체하므로 사용자 승인과 배포 담당 세션(원격 호출 규칙) 경유로만 한다.
7. 재채점 입력용 zip을 갱신하려면 새 번들에서 `GET /api/bundles/<id>/export/bundle.zip`로 내려받아 `datasets/0929_label_viewer_full_result.zip`을 교체한다(다음 재채점 전 필요).

로컬 뷰어(`localhost:8765`)는 파일 mtime으로 캐시를 무효화하므로 재시작 없이 반영된다.

## Update 2026-10-03 — 모든 열에 '인쇄된 값만' 적용, 소수 금액 유지

날짜: 2026-10-03

워크트리: 해당 없음

### 규칙

- 사용자가 승인한 규칙(2026-10-03)이다. 세부내역서 표의 모든 열에서, 문서에 인쇄된 값만 정답 칸에 둔다.
- 관례나 계산으로 채운 미인쇄 칸은 빈칸으로 바꾼다. 빈칸 표기는 위와 같다. `value`·`predicted_value`를 `""`로 두고, `None`은 그대로 둔다. 예:
  - 단가 열이 없는데 단가 = 총액으로 채운 칸
  - 총액 열이 없는데 급여액을 총액에 복사한 칸
  - '급/비' 표시를 보고 금액을 비급여에 옮겨 적은 칸
  - 선택진료 열이 없는데 0으로 채운 칸
- 금액은 인쇄된 그대로 두고 소수점도 남긴다. 인쇄값으로 고친 칸은 `value`만 바꾼다(`predicted_value`는 AO 원본).
